# PalForge

A modern Palworld mod manager designed to make installing, organizing, and updating mods simple.

PalForge helps players manage Palworld mods from multiple modding frameworks without manually sorting files or remembering different installation methods.

> 🚧 PalForge is currently under active development.

---

## Features

- Automatic mod type detection
- One-click installation
- Dependency checking
- Conflict detection
- UE4SS support
- PalSchema support
- Blueprint / LogicMods support
- Pak mod support
- CurseForge integration (planned)
- Automatic update checking (planned)

---

## Goals

PalForge aims to provide a simple and reliable experience for managing Palworld mods while respecting mod authors and the CurseForge ecosystem.

The application does **not** redistribute mods. Users are always directed to official project pages and official download sources.
